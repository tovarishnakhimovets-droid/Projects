# Projects

Общий репозиторий команды. Каждый участник работает в локальной копии и своей
ветке; изменения объединяются через pull request. Рабочие чертежи и установленные
серверы хранятся отдельно от исходников.

- [cad-bridge](cad-bridge/README.md) — общий MCP-мост для AutoCAD 2026 и 2027,
  исходники, тесты и сборка установочного ZIP.

Ветки: `main` — принятые версии, `develop` — совместная разработка,
`feat/...` — отдельная доработка. Git-команды и merge выполняет пользователь;
агент готовит код и проверяет результат.
