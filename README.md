# Projects

Общий репозиторий команды. У каждого своя локальная копия и постоянная ветка
(`andrew`, `artem` и другие согласованные имена). Принятый общий код — `develop`;
правки включаются через Pull Request. Коммиты, push и обычный merge выполняет человек; автопул разрешён по AGENTS.

[CAD-мост 2026/2027](cad-bridge/README.md) — исходники, инструменты и установщик.
[Краткая памятка совместной работы](cad-bridge/docs/TEAM_SETUP.md) — подключение,
доработки, выпуск и обновление. Рабочие чертежи хранятся отдельно от сервера.
