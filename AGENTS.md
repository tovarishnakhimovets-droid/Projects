# Team projects

Read the selected project's AGENTS.md before editing its code. The AutoCAD
bridge project is cad-bridge; it has one shared source tree for 2026 and 2027.
Keep drawing conventions in drawing-project instructions.

The user owns Git setup, branches, staging, commits, pushes, pull requests and
merges. Explain short executable steps and inspect results. Do not perform Git
mutations or remote publishing unless that specific step is explicitly delegated.
Merges remain with the user. The agent edits, builds and runs offline checks.

Inspect existing changes before editing; preserve other chats' work. Do not
commit local credentials, MCP configurations, build output or installed runtimes.
