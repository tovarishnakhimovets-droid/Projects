# Установка и обновление CAD-моста

Полный порядок действий находится в **одной памятке TEAM_SETUP.md**:

- В исходниках Git: `cad-bridge/docs/TEAM_SETUP.md`.
- В распакованном ZIP: [server/bridge-docs/TEAM_SETUP.md](server/bridge-docs/TEAM_SETUP.md).
- Если этот файл открыт из папки bridge-docs: [соседний TEAM_SETUP.md](TEAM_SETUP.md).

В памятке три процесса: подключение новой машины, совместная доработка в личных
ветках, сборка и обновление всех машин из общей папки установщика на NAS.
Версия и состав конкретного пакета находятся в manifest.json.
