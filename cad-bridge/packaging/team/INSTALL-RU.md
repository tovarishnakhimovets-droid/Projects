# Установка CAD-моста для AutoCAD 2026/2027 и Codex

Пакет `DwgMcp.Setup-v2.0.1-team.2-win-x64.zip` содержит плагины AutoCAD 2026 и 2027
и устанавливается отдельно на каждом компьютере Windows x64. Нужны установленный
AutoCAD выбранного года и локальный Codex с разрешёнными MCP-подключениями.
Подписка Business не переносит локальный
сервер, пользовательские инструкции или историю чатов коллеге автоматически.

PR #2 с импортом исходников в `Projects/cad-bridge` слит в `develop` 2026-10-07.
Исходники и общие правила находятся в одном проекте `cad-bridge`.
На компьютере автора source root — `D:\CAD-Automation\team\Projects\cad-bridge`;
действующий runtime AutoCAD 2027 сохранён в
`D:\CAD-Automation\releases\dwg-2027\2026-10-06-style-tools`.
Установка пакета на другом компьютере выполняется отдельно по инструкции ниже.

`2.0.1-team.2` — версия этого командного пакета; версия upstream/MCP остаётся `2.0.1`.
Для запуска не нужны отдельные Python, .NET 8 Runtime или SDK: внешний сервер
самодостаточный, а среду плагина предоставляет AutoCAD: .NET 8 для 2026 и .NET 10
для 2027. AutoCAD 2026 Update 1.2 переходит на .NET 10; здесь выбран подтверждённый
у ГИПа AutoCAD 2026 с .NET 8, принудительное обновление не требуется.

## 1. Установить пакет

Скачать: [ZIP team.2 для AutoCAD 2026/2027 с Яндекс Диска](https://disk.yandex.ru/d/tzTFb_evK8vwJg).
2026-10-07 публичные метаданные подтвердили размер 39 622 751 байт и SHA256:

```text
d74a568bbfccb462987d7cff82f9d05c8108e9c1b267a45338f83a7c9bee092d
```

После скачивания из папки с ZIP выполните
`Get-FileHash -LiteralPath .\DwgMcp.Setup-v2.0.1-team.2-win-x64.zip -Algorithm SHA256`.
`-LiteralPath` задаёт точное имя файла; `-Algorithm SHA256` выбирает алгоритм.
Значение `Hash` должно совпасть с указанным выше. ZIP не пересобирался при
очистке; внутри сохранены документы и manifest времени его сборки.

1. Скачайте ZIP по ссылке выше в локальную папку. Разблокируйте ZIP до
   извлечения: через пункт «Разблокировать» в его свойствах либо командой
   `Unblock-File -LiteralPath .\DwgMcp.Setup-v2.0.1-team.2-win-x64.zip` из папки с ZIP.
   Установщик разблокирует сервер, но не файлы плагина.
2. Извлеките весь архив, например в `C:\CAD\dwg-setup`. Откройте Windows
   PowerShell в извлечённой папке. Не запускайте установку внутри ZIP.
3. Закройте все окна AutoCAD и Codex. Для компьютера ГИПа с AutoCAD 2026 выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Years 2026 -Client none
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-codex.ps1 -AcadYear 2026
```

На исходном компьютере с AutoCAD 2027 используйте:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Years 2027 -Client none
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-codex.ps1 -AcadYear 2027
```

`-NoProfile` отключает личный профиль PowerShell; `-ExecutionPolicy Bypass`
разрешает этот скрипт в запущенном процессе; `-File` задаёт скрипт. `-Years`
выбирает год плагина; `-Client none` оставляет настройку клиента второму скрипту;
`-AcadYear` выбирает год подключения Codex. `Unblock-File` снимает отметку
скачанного файла; `-LiteralPath` задаёт его точное имя.

Первый скрипт устанавливает плагин выбранного года и общий сервер. Второй
регистрирует `dwg-2026` или `dwg-2027` через Codex CLI, если он доступен,
и добавляет указатель на инструкции моста
в пользовательский `AGENTS.md`, сохраняя существующий текст. Если CLI не найден,
скрипт выводит TOML: добавьте этот блок в файл конфигурации Codex по указанному
им пути. Не создавайте второй блок с тем же именем подключения. Повторный запуск
обновляет существующий указатель на инструкции, включая блок от первого выпуска.

Пути установки:

- Плагин: `%APPDATA%\Autodesk\ApplicationPlugins\Bimwright.Dwg.bundle`.
- Сервер: `%LOCALAPPDATA%\Bimwright\Dwg\server\current\dwg-mcp.exe`.
- Инструкции: `%LOCALAPPDATA%\Bimwright\Dwg\server\current\bridge-docs\AGENTS.md`.

Профиль подключения: AutoCAD выбранного года, toolsets `query,modify,drawing,view`,
`BIMWRIGHT_DWG_READ_ONLY=false`, `BIMWRIGHT_DWG_ENABLE_TOOLBAKER=false`.
Установщик может создать общий JSON с `toolsets=["all"]`; явные параметры
подключения `dwg-2026` или `dwg-2027` задают нужный ограниченный профиль.

## 2. Проверить подключение

Запустите AutoCAD выбранного года и откройте нужный чертёж. Плагин в папке ApplicationPlugins
предназначен для автоматической загрузки при старте. Затем запустите Codex
и откройте новый локальный чат. Попросите:

> Прочитай инструкции общего моста и через dwg-2026 покажи сведения об активном
> чертеже. Ничего не изменяй и не сохраняй.

Для AutoCAD 2027 укажите в запросе `dwg-2027`. Если CLI доступен, регистрацию
можно проверить отдельно для нужного года:

```powershell
codex mcp get dwg-2026 --json
# Для AutoCAD 2027: codex mcp get dwg-2027 --json
```

`--json` выводит конфигурацию в формате JSON.

Эта команда проверяет конфигурацию, а не связь с AutoCAD. Если подключение
отсутствует, проверьте вывод `setup-codex.ps1` и перезапустите Codex. Если сервер
запустился, но AutoCAD недоступен, проверьте загрузку плагина и ограничения
администратора. Не отключайте защиту AutoCAD для обхода сообщения об ошибке.

Для предварительного просмотра установки используйте те же команды с `-WhatIf`.
Предпросмотр проверяет комплект и показывает будущие изменения; он не запускает
сервер и не подтверждает работу плагина. При наличии другого машинного bundle
с тем же ProductCode установщик остановится и укажет конфликтующий путь.

## Работа с чертежами и обновления

Работайте с активным документом; сохраняйте DWG только по прямой просьбе.
AutoLISP этим мостом не исполняется. Для обычных задач не нужны тестовые DWG
или повторный запуск уже успешных проверок.

Для обновления получите новый версионный ZIP, закройте AutoCAD и Codex и повторите
установку. Путь сервера остаётся постоянным. Синхронизируйте через Яндекс Диск
ZIP и документацию; каждый участник устанавливает их локально.

Профиль обоих годов содержит те же 42 инструмента. Три операции оформления
(`dwg_set_lineweight`, `dwg_set_layer_lineweight`, `dwg_create_hatch`) ранее
проверены в живом AutoCAD 2027. Работа плагина в AutoCAD 2026, установка этого ZIP
и живое подключение на компьютере ГИПа ещё не подтверждены; все 42 инструмента
не считаются живо проверенными.

Исходники для разработки находятся в общем monorepo `Projects`, каталог
`cad-bridge/`. Пользователь выполняет clone общего репозитория, выбирает
согласованную ветку и переходит в `cd .\cad-bridge` из корня `Projects`.
В `upstream/dwg-mcp` уже включены локальные исправления; повторно клонировать
upstream или применять `patches/` не требуется. Патчи сохраняют снимок уже
применённых изменений;
дальнейшие изменения, коммиты, push и merge ведёт пользователь в Git `Projects`.

Для разработки указатель можно направить на локальный
каталог `cad-bridge`, содержащий `AGENTS.md`, `docs/CAD_WORKFLOW.md` и
`WORK_STATUS.md`. Команда выполняется из извлечённого ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-codex.ps1 -AcadYear 2026 -BridgeSourceRoot 'D:\CAD-Automation\team\Projects\cad-bridge'
```

Для AutoCAD 2027 замените `-AcadYear 2026` на `-AcadYear 2027`.
`-BridgeSourceRoot` указывает на исходники, документацию и состояние разработки
в своем checkout; он не устанавливает другую DLL.

На другом компьютере замените путь после `-BridgeSourceRoot` своим локальным
путём к `Projects\cad-bridge`. Для установки готового ZIP checkout исходников
не требуется. Работа с исходниками и offline helper-проверки описаны в
`docs/TEAM_SETUP.md` общего проекта.

В новых пакетах `server/bridge-docs/AGENTS.md` создаётся точным копированием
канонического `cad-bridge/AGENTS.md`; отдельная редактируемая копия правил
runtime в исходниках не поддерживается. Пользователь готового runtime читает
установленные правила; развитие моста требует отдельного checkout Projects.
