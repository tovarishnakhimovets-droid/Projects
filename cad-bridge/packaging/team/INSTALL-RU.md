# Установка CAD-моста для AutoCAD 2026/2027

В этом ZIP — согласованный сервер, плагины обоих годов, установщик и инструкции.
Точная версия и состав находятся в manifest.json. Пакет устанавливается
локально на каждом компьютере; опубликованные файлы на NAS не редактируются.

Полная инструкция: [TEAM_SETUP.md](server/bridge-docs/TEAM_SETUP.md).
Если этот файл открыт из server/bridge-docs, откройте соседний TEAM_SETUP.md.

1. Возьмите версионный ZIP и его .sha256 из опубликованного выпуска на NAS.
   Проверьте SHA256 по полной инструкции и извлеките ZIP в локальную папку.
2. Закройте AutoCAD и Codex. В Windows PowerShell из извлечённой папки выполните
   установку своего года:

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Years 2026 -Client none
~~~

Для AutoCAD 2027 замените 2026 на 2027. -NoProfile отключает профиль
PowerShell; -ExecutionPolicy Bypass разрешает скрипт в этом процессе; -File
задаёт скрипт; -Years выбирает плагин; -Client none сохраняет настройку клиента.

3. При первой установке настройте подключение:

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-codex.ps1 -AcadYear 2026
~~~

-AcadYear выбирает год MCP-подключения; для 2027 замените число. При обновлении
существующего подключения повторная настройка обычно не требуется.

4. Запустите AutoCAD, затем Codex. Первая проверка — сведения об активном
   чертеже через dwg_get_drawing_info, без изменений и сохранения.

Профиль query,modify,drawing,view нового выпуска содержит 58 инструментов.
Запуск доверенных .lsp описан в server/bridge-docs/CAD_WORKFLOW.md;
пользовательские файлы из отдельной рабочей папки lisp в этот ZIP не включены.
Самодостаточный сервер не требует Python или отдельного .NET Runtime; плагин
использует среду AutoCAD. Сборки и offline-проверки не заменяют нативную проверку
операций после установки. Обновление не выполняется посреди рабочей сессии.
