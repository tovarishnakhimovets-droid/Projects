# AutoCAD MCP: общий мост команды

Один сервер и два плагина: AutoCAD 2026 / .NET 8 и AutoCAD/Civil 3D 2027 / .NET 10.
На каждом компьютере мост установлен локально; все проекты чертежей используют
эту установку. Общая папка на NAS служит для установки проверенных версий.

Начать с **[памятки полного цикла](docs/TEAM_SETUP.md)**: новая машина,
доработка в личной ветке, сборка и обновление всех машин.

| Путь | Содержимое |
| --- | --- |
| [AGENTS.md](AGENTS.md) | Единственные правила работы для чатов |
| [docs/CAD_WORKFLOW.md](docs/CAD_WORKFLOW.md) | Устройство моста и технический процесс доработки |
| [docs/TOOLS.md](docs/TOOLS.md) | Общий справочник контрактов инструментов |
| [WORK_STATUS.md](WORK_STATUS.md) | Очередь, выполненные проверки и оставшаяся работа |
| `dwg-mcp/src/`, `dwg-mcp/tests/` | Единственная реализация и .NET-тесты |
| [lisp/](lisp/) | Общие AutoLISP-команды; исходники и запуск из локальной копии Git |
| `tools/` | Командная упаковка и MCP-диагностика |
| `packaging/` | Настройка Codex и указатель на памятку для установщика |
| `releases/<версия>/` | Локальные результаты сборки, исключены из Git |
| `patches/`, `docs/IMPORT_MANIFEST.json` | История импорта upstream; патчи уже применены |

Исходники основаны на [bimwright/dwg-mcp v2.0.1](https://github.com/bimwright/dwg-mcp).
Лицензия и уведомления сохранены в `dwg-mcp/LICENSE` и
`dwg-mcp/THIRD_PARTY_NOTICES.md`. Изменение исходников или merge не обновляет
установленные DLL/EXE. Документационные правки не требуют пересборки установщика.

Настройки AutoCAD и перекрестия описаны в [общем справочнике](docs/TOOLS.md#settings).
Создание, обновление и запуск LISP — в [технической инструкции](docs/CAD_WORKFLOW.md#создание-и-обновление-autolisp).
Перевод текста и Unicode-оформление — [единый сценарий](docs/CAD_WORKFLOW.md#перевод-и-оформление-текста);
возможности выносок — [справочник](docs/TOOLS.md#leaders).

## Навыки работы с чертежами

- [Подсчёт блоков ФБС по профилю](.agents/skills/count-fbs-profile/SKILL.md) —
  ведомость по рамкам с учётом числа труб, дубликатов и спорных выносок.
  Вызов: `$count-fbs-profile` в контексте этого проекта; из другого проекта
  передайте путь к SKILL.md явно. Это инструкция Codex, а не новый MCP-метод.
